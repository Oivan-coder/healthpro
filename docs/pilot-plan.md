# Pilot Plan

## Scope

- 50–200 patients.
- 30–50 laboratory indicators.
- One clinic or laboratory contour.
- No complex AI in the first stage.
- Focus on structured data, dynamics and patient understanding.

## Success Metrics

- Patients opening the cabinet after lab result notification.
- Repeated opens of the lab section.
- Transitions from abnormal indicators to appointment booking.
- Repeat lab orders.
- NPS/CSAT after viewing results.
- Reduced questions like "what does my analysis mean?".

## Pilot Steps

1. Agree on test cohort and consent process.
2. Receive lab result export and local code dictionary.
3. Map indicators into the Атлас здоровья catalog.
4. Run import in backend demo contour.
5. Validate UI with clinicians.
6. Launch limited patient test.
7. Review metrics and decide on MIS/LIS API integration scope.
